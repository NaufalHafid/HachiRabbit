# Hachi Rabbit — Landing Page

Landing page semi-gallery untuk budidaya kelinci Hachi Rabbit.

## Isi
- Hero section dengan logo Hachi Rabbit
- AOS scroll animations
- Responsive navbar + mobile menu
- About section
- Breed cards: Fuzzy Lop, Rex, Holland Lop, Netherland Dwarf
- Gallery dengan filter
- Gallery lightbox
- Hover animation + mouse parallax
- CTA Instagram / WhatsApp
- Responsive desktop, tablet, mobile

## Cara menjalankan
1. Extract ZIP.
2. Buka `index.html` di browser.
3. Internet diperlukan untuk font Google Fonts dan library AOS dari CDN.

## Cara memasukkan foto kelinci asli
Buat folder:
`assets/gallery/`

Lalu masukkan foto seperti:
- `fuzzy-01.jpg`
- `fuzzy-02.jpg`
- `rex-01.jpg`
- `rex-02.jpg`

Kemudian bagian `.gallery-visual` di `index.html` bisa diganti menjadi:
`<img src="assets/gallery/fuzzy-01.jpg" alt="Fuzzy Lop Hachi Rabbit">`

## Link Instagram / WhatsApp
Cari bagian `CTA` di `index.html`, lalu ganti `href="#"` dengan link asli.

Contoh:
Instagram:
`https://instagram.com/hachirabbit`

WhatsApp:
`https://wa.me/62xxxxxxxxxx`

## Warna
Tema dibuat dari logo: cream, warm brown, caramel, dan sage green.
